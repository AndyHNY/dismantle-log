# Dismantle Log

An offline tablet app that technicians use to record parts as they come off an asset: one question per screen, photos, and manager sign-off for extra parts. It exports a stock CSV and photos ready for upload.

Served with GitHub Pages. Job data and photos stay on each tablet. Only the app's code is in this repository.

When you change files, bump `VERSION` in `sw.js` so the tablets pick up the update.
